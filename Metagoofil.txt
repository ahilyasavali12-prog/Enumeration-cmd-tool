## 📌 Overview

**metagoofil** is an information-gathering tool designed for extracting metadata from public documents belonging to a target organisation. It automates Google searches to identify and download documents of specified file types from a target domain, enabling OSINT analysts and penetration testers to harvest metadata for reconnaissance.

> ⚠️ **Disclaimer:** This tool is intended for authorised penetration testing, security research, and educational purposes only. Always obtain proper written permission before running reconnaissance against any target. Unauthorised use may violate computer crime laws.

## 🚀 Usage

### Basic Syntax

```bash
metagoofil -d <DOMAIN> -t <FILE_TYPES> [OPTIONS]
```

### Full Options Reference

```
usage: metagoofil.py [-h] -d DOMAIN [-e DELAY] [-f [SAVE_FILE]]
                     [-i URL_TIMEOUT] [-l SEARCH_MAX] [-n DOWNLOAD_FILE_LIMIT]
                     [-o SAVE_DIRECTORY] [-r NUMBER_OF_THREADS] -t FILE_TYPES
                     [-u [USER_AGENT]] [-w]
```

| Flag | Parameter | Description | Default |
|------|-----------|-------------|---------|
| `-d` | `DOMAIN` | Target domain to search (**required**) | — |
| `-t` | `FILE_TYPES` | File types to search e.g. `pdf,doc,xls` (**required**) | — |
| `-l` | `SEARCH_MAX` | Maximum number of search results | `100` |
| `-n` | `DOWNLOAD_FILE_LIMIT` | Max files to download per type | `100` |
| `-o` | `SAVE_DIRECTORY` | Directory to save downloaded files | `.` (cwd) |
| `-f` | `SAVE_FILE` | Save HTML links to file (omit = don't save) | — |
| `-e` | `DELAY` | Delay (seconds) between searches | `30.0` |
| `-i` | `URL_TIMEOUT` | Timeout in seconds for unreachable pages | `15` |
| `-r` | `NUMBER_OF_THREADS` | Number of downloader threads | `8` |
| `-u` | `USER_AGENT` | Custom User-Agent string | Googlebot |
| `-w` | — | Download files (instead of view-only) | — |

## 🧪 Usage Examples

### Example 1 — Basic PDF Scan

Scan a domain for PDF files, retrieve up to 100 results, download 25, and save output:

```bash
metagoofil -d kali.org -t pdf -l 100 -n 25 -o kalipdf -f kalipdf.html
```

### Example 2 — Multiple File Types

Search for Word and Excel documents:

```bash
metagoofil -d example.com -t doc,docx,xls,xlsx -l 200 -n 50 -o output_docs -w
```

---

### Example 3 — Stealth Mode (Custom User-Agent + Delay)

Slow down requests and randomise User-Agent to reduce detection:

```bash
metagoofil -d target.com -t pdf,pptx -l 50 -n 10 -e 60 -u -o stealth_output
```

---

### Example 4 — View Results Only (No Download)

Enumerate URLs without downloading files:

```bash
metagoofil -d company.com -t pdf -l 100 -f links.txt
```

## 🔎 Metadata of Interest

When documents are downloaded, analysts can extract metadata using tools like **ExifTool** or **strings**:

- **Usernames / Author names** — leaked internal user accounts
- **Software versions** — OS, Office version, PDF generators
- **Email addresses** — from document properties
- **File paths** — internal directory structures
- **Creation & modification dates** — activity timelines
- **Printer/machine names** — network asset info

```bash
# Extract metadata with ExifTool (post-download)
exiftool kalipdf/*.pdf
```
